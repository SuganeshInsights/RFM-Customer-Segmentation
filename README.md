# RFM Analysis for Customer Segmentation

This project implements **RFM (Recency, Frequency, Monetary)** analysis to segment customers into four categories: **Low**, **Medium**, **High**, and **Top** value. By analyzing customer behavior based on these three key metrics, businesses can optimize marketing strategies, improve customer retention, and drive targeted campaigns.

### Key Features
- **Recency (R)**: How recently a customer made a purchase.
- **Frequency (F)**: How often a customer makes a purchase.
- **Monetary (M)**: How much money a customer spends.

### Customer Segmentation
Customers are classified into four value segments:
- **Low-value**
- **Medium-value**
- **High-value**
- **Top-value**

### Purpose
This analysis helps businesses:
- Identify top-performing customers for loyalty programs.
- Target high-value customers with personalized offers.
- Retain medium and low-value customers with tailored marketing strategies.
